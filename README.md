# YourHealth – A Guide for a Healthier You

YourHealth is a static health education website designed to provide accessible and informative health-related content for different age groups and communities. The website aims to help users explore health topics, understand healthy lifestyle practices, and make better-informed health decisions.

## Project Overview

YourHealth provides health information through several categories, allowing users to explore content based on their needs and interests.

The website uses a simple, clean, and responsive design to make health information easier to navigate and read.

## Main Features

- **Home Page** – Introduces the YourHealth platform and provides access to its main sections.
- **Women's Health** – Provides educational information about women's health, including mental health, nutrition, fitness, health essentials, and period education.
- **Men's Health** – Covers health topics relevant to men, including mental health, nutrition, fitness, and preventive care.
- **Children's Health** – Provides information about children's mental health, physical activity, nutrition, health essentials, and growth and development.
- **Senior Citizen's Health** – Presents health information and guidance for older adults.
- **Health on a Budget** – Shares health-related information and practical guidance with consideration for affordability.
- **Dropdown Navigation** – Allows users to access subtopics through the category navigation menu.
- **Table of Contents** – Helps users navigate directly to specific sections within an article page.
- **Responsive Layout** – Uses CSS media queries to adapt the website layout to different screen sizes.

## Technologies Used

- **HTML5** – Structures the website content and page elements.
- **CSS3** – Controls the visual appearance, layout, typography, navigation, and responsive design.
- **Google Fonts** – Uses the Playfair Display font for selected headings.
- **Unsplash** – Provides images used in the website.

## Website Structure

The website consists of several HTML pages representing the main health categories. Each page uses shared styling from the CSS stylesheet.

Main website sections include:

- Home
- Women's Health
- Men's Health
- Children's Health
- Senior Citizen's Health
- Health on a Budget
- References

## Design and Navigation

The website uses a green and neutral color palette to create a clean and comfortable reading experience.

Its navigation system includes dropdown menus, active-page indicators, and internal page links. Article pages also provide a table of contents that links directly to individual content sections using HTML anchor IDs.
